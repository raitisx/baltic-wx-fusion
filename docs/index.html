TT Aero Meteo

5-model skill-weighted forecast — DWD ICON · MET Norway MEPS · ECMWF IFS · NOAA GFS · UK Met Office UM, blended by 30-day local skill (station + METAR verification; equal weights until ≥20 samples). Meteogram is live; the fused map refreshes each morning; radar is observed (past only). Times in Europe/Riga.
Cloud base is model-derived (LCL), verified against METAR ceilings — treat <1 km detail as guidance, not gospel.
One slider moves all three columns (identical extent) · drag across the meteogram to move the maps, hover to read an hour · click any 25 km cell to add it. Dots: blue = airports (METAR), teal = national stations (rain + humidity), named = cities.
